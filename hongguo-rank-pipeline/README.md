# 红果短剧推荐榜采集工作流

这是可反复调用的 Agent Skill，适合短剧选题、榜单整理和按日期保存榜单快照。当前执行器支持红果 App 的“推荐榜”；热播榜、臻果榜等未验证，不能直接宣称兼容。默认范围为“全部类型、分类总榜”，也可由 Agent 先在手机筛选，再按实际范围记录。

## 数据维度

| 字段 | 含义 |
|---|---|
| 排名、剧名 | 榜单顺序、页面结构可读取的完整名称 |
| 类型、题材、人物信息 | 保留榜单原文，人物可能是演员或角色，不强行推断 |
| 推荐数、热度、点赞 | 保留“万”等页面单位和原文，不把展示约数当精确统计 |
| 评分、标签 | 仅保存页面实际展示的值，未展示评分留空 |
| 榜单文案 | 剧情简介或短评/推荐语，不假称全部都是完整剧情 |
| 封面 | 从当前截图裁剪并嵌入 Excel，不需要单独传图片目录 |
| 采集时间、榜单与筛选范围 | 用来区分不同时段、类型和分类的快照 |

## 亮点优势

- 一次任务按排名补足目标，重复屏幕去重、互补缺失字段；中断保留检查点，可显式续采。
- 只读榜单并滚动，不逐部打开详情；结构能提供完整剧名、文案时直接读取，避免根据省略号猜测。
- 按页面层级定位卡片、排名和封面，减少对固定屏幕坐标的依赖；换手机仍先试采核验。
- 输出带封面 Excel；每次独立命名，可由 Agent 定时保存快照用于后续比较。
- 保留原始证据供本机核查，并标明“当前账号可见”，不把个性化推荐榜说成统一全站排行。

## 怎么用

保持整个项目目录完整，共用 `../ps-list-pipeline/scripts/` 的 ADB 与 Excel 执行器。接收方需要 Windows 10/11、PowerShell/.NET、安卓手机和 ADB；无需 Python 或 Office。

把项目交给具备本机命令及截图能力的 AI：

> 阅读 hongguo-rank-pipeline/SKILL.md，采集红果短剧“全部类型、推荐榜、分类总榜”前50名。先检查当前手机并试采核验，再正式采集。保存页面可读字段和封面，最终输出一个带图 Excel；未展示的数据留空，说明个性化排序与未达到目标的情况。

执行前，由 Agent 导航到正确榜单、筛选范围和榜首。执行器不会替用户切换分类：

```powershell
.\hongguo-rank-pipeline\scripts\run_rank.ps1 -Limit 50 -TypeFilter 全部 -Category 总榜 -OutDir '.\结果'
```

`-AdbPath` 指定工具，`-Serial` 指定手机；`-KeepData` 保留核查数据。底层 `collect_rank.ps1 -Resume -OutDir <原检查点目录>` 可在同一榜单快照内续采，不能把昨天的数据接到今天。`-ReplayDir` 只用于离线证据验证，不能标为实机新采集。

## 定时自动化

可以让支持定时任务的 Agent 调用此 Skill。调度器在 Agent 侧，采集器没有独立常驻时钟。WorkBuddy 的设置方式见[官方定时任务文档](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Automation-Guide)。本地手机任务要求电脑和 Agent 运行、手机连接并解锁、App 已登录；普通云端任务不能自动访问本机 USB 手机。

定时任务提示词示例（需由使用者选择时间并创建，示例不是已启用的计划）：

> 每天09:00（Asia/Shanghai）在本项目目录调用 hongguo-rank-pipeline/SKILL.md，重新确认红果“全部类型/推荐榜/总榜”，返回榜首，采前50名并保存带图 Excel，以本次时间命名。不得复用上一次榜单结果或覆盖历史快照。若设备断开、锁屏、登录失效、页面变化或工具权限不足，保留已采数据，报告原因并等待处理；不要通过改变安全设置强行继续。同一手机不并发运行采集任务。

## 实际边界

已在原设备实采前50名、50张封面；新手机、字体或 App 版本仍需 Agent 根据截图/XML 验证。进入另一个榜单、榜首缺失或同一排名的剧名在采集中变化时会停止。可见评分、点赞、文案不保证每条都具备。排名反映采集时间区间内当前账号页面，不能承诺全网统一或瞬时一致。
